    How the price is earned

    The curve is fitted to the snapshot’s own traded tokens — — — not typed in by hand. Every factor comes from the protocol’s own record: its TVL, its seven-day growth, and how many chains it runs on. Age still matters for the hold window and the launch odds — but the price no longer carries a maturity multiplier: the quadratic curve prices age better without it. No protocol’s name ever changes its score. Each row carries the band the backtest earns: the full model’s leave-one-out median miss, so a value of $10M reads as roughly $3M–$36M instead of a false precision.

    Farm economics, stated

      Growth, chains, odds — and the maturity that left

      • Growth: 7-day change clamped to −60%…+120%, half weight — fitted as an effect first, and it missed worse, so it stays an adjustment, validated as part of the full model. Relative momentum (7d vs the market median) was tested both ways and now loses leave-one-out outright, so it stays out.
      • Maturity: dropped in radar-8. The quadratic curve with growth and chains — no maturity multiplier — wins leave-one-out and both blind splits and confirms on walk-forward; putting maturity back (quadratic with all three multipliers) loses blind 2024, and the maturity-only quadratic has the best leave-one-out of any variant but loses both blind splits. Age is not ignored: it still sets the hold window and drives the launch odds.
      • Chains: +2% per extra chain, capped at +10% — fitted as an effect first, and it missed worse. Dropping it wins leave-one-out and blind 2024 but loses blind 2025, so it stays in.
      • Launch odds: a separate logistic model on age + category, 1 minus the fitted peer token rate — the share of protocols this age in this category that still record no token. It never changes the implied value; it weights the expected slice in the detail view. Weighting the ranking by odds was tested on both blind sets and does not rank better (blind 2025 top-10: 50% raw vs 40% weighted), so the board ranks by raw launch value.

      Read this before farming

      “Pre-token” means the protocol’s record carries no token — no market cap, no CoinGecko id, no symbol — not that it has promised one. Implied value is a ranking model fitted to traded tokens, not a price prediction: it says which launch would be biggest if it happened, not that it will happen or what a token would trade at. Launch odds are the peers’ record — the share of protocols this age in this category that still record no token — not a forecast that a token will launch. The farm net is a scenario — 10% of the implied value shared pro-rata by TVL among depositors, on a $1,000 position — not a promise of any payout. Airdrops are never guaranteed, claims never ask you to pay, and the farm plans above are starting points, not advice. Verify every link on the protocol’s own site before you connect a wallet.
